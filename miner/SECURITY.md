# Safe testing

Mine only on machines you own or are authorized to use. Do not paste a wallet
seed, private key, SSH password, API token or exchange password into this project,
its website, or a public issue. The website's configuration helper is optional;
it creates a file in your browser and does not submit the form to a server.

Check downloaded files against the published checksums. Checksums are not
signatures and do not independently establish publisher identity. Review code
and use appropriate security tools; do not blindly bypass antivirus warnings.
Stop on invalid hashes, a source-integrity failure, or unexpected payout settings.

No private vulnerability-reporting channel has been configured at this stage.
For a sensitive vulnerability, request a private contact channel from the project
owner without posting exploit details or credentials publicly.
