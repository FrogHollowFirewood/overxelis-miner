Privacy / safety

Keep your keys.
Keep your control.

This website

This is a static project website. It contains no browser mining, analytics, advertising scripts, remote fonts, cookie banner, account sign-up, or payment form. No project-operated server receives the configuration-helper fields. The helper creates a local file in your browser; it uses no cookies or local storage.

The hosting provider may process ordinary access information, including IP addresses, for delivery and security. External links open third-party services with their own policies. Public GitHub issues can be read by anyone.

The miner

The miner sends your public payout address, worker name, pool worker password, and shares to the pool you choose. During disclosed developer-fee windows it connects to the fixed developer pool/address. Pool operators see connection information. TCP is unencrypted; use a pool-supported TLS endpoint when available. The developer endpoint in this beta uses TCP.

Do not share secrets

No seed phrase, wallet private key, exchange password, or deposit is needed. Never publish an unredacted config or log. Downloaded config files may use your browser’s default permissions; move the file into the miner folder and run chmod 600 config.json.

Experimental software

Use only computers you own or are authorized to operate. Mining uses CPU resources and electricity and may increase heat and fan noise. Stop on correctness failures or unexpected payout settings. No performance, income, security, or availability guarantee is made.

Reporting a security issue

No private vulnerability-reporting channel has been verified yet. Ask the project owner for a private contact channel before disclosing sensitive details. Do not post passwords, keys, or exploitable private-system details to a public issue.

Independent identity

OverXelis is not affiliated with or endorsed by the XELIS project, Kryptex, or a hosting provider. The site’s dark/mint design is inspired by the XELIS ecosystem, but its branding and layout are original to this project.

Configuration-form safety

All configuration fields and the submit button stay disabled until the local download handler is attached. Without JavaScript, or if that script fails to load, use the terminal wizard instead. Source downloads, documentation, GitHub feedback, and the feedback template remain available without scripts. A page-level content policy also blocks form submissions and script-initiated network connections. Official project links open their own sites and are subject to those sites’ privacy policies.
