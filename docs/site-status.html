Release / testing status

Know what is tested.

OverXelis Miner 1.0.0-beta.2 · Public Source Preview 2. This is experimental Linux x86-64 CPU software, not a stable binary release.

Available now

The named Linux source archive, SHA-256 checksum, installation guide, local configuration helper, and public GitHub issue forms. Website downloads do not require signing in.

Still under validation

Repeated fee-cycle reliability, 24-hour stability, broader platform compatibility and permissions on other systems remain open. Native checks, accepted work and one real fee transition were observed on one desktop before a maintainer-requested early stop.

Preview 2: attribution corrected, old release preserved

The package notice now distinguishes historical development files from shipped files. kernels/rc1.c is historical and is not included. The notice also identifies the conditional TNN-derived ChaCha path used by the selected kernel, with its license retained. Mining algorithms, pool behavior and the fee policy are unchanged.

At release preparation, 62 offline tests passed from the exact new archive. The native build gate initially refused while another CPU miner was active; no guard was bypassed. After that miner was stopped by its owner, the native checks, initial live tests and one real fee transition were documented. The later huge-page observation was ended early at the maintainer’s request; it did not complete 24 hours. Read the version-specific correction and test record.

Current Preview 2 release · Preserved Preview 1 release. Existing releases and their assets have not been silently replaced.

Final partial validation — ended early

29 October 2026 (UTC): the maintainer deliberately ended the exact Public Source Preview 2 huge-page test after 2 hours 55 minutes 51 seconds of observer elapsed time. The planned 24-hour stability test was not completed. This is a record of completed functional stages and one observed fee cycle, not an unqualified stability pass.

Observed live work

1,193 accepted USER shares and 6 accepted FEE shares, with final reported rejected and unresolved counts both zero. All 192 workers used huge pages. The final displayed gross session average was 110.342 kH/s.

Requested early stop

The stop was requested at 15:31:46 UTC. Native workers closed at 15:31:47 UTC; the observer finalized at 15:31:52 UTC. Exit code 130 reflects the handled interruption. No fatal log message or forced termination was recorded.

The unchanged public archive had already passed a normal-user native build and all 1,031 retained inputs across four C implementations, with full scratchpad comparisons, replayed Rust-reference answers and the public CLI self-test. Rust was not newly rebuilt or executed. The separate 180-second ordinary-memory test ended normally with 23 accepted user shares, zero reported rejections or unresolved submissions, and a 92.462 kH/s session average.

One real USER → FEE → USER transition

The fee window began at 14:15:02 UTC and ended at 14:16:02 UTC. Developer authorization and six accepted developer shares were followed by USER reauthorization and renewed accepted USER work. No window was skipped. The measured interval between fee-start and fee-end log entries was 60.029 seconds, with 59.243 seconds of recorded fee-active work; this is not a hard-real-time 60.000-second guarantee.

Final accounting recorded 10,484.358 USER-active seconds and 59.243 FEE-active seconds. The full observer interval was 10,550.559 seconds and includes startup and cleanup; its difference from active time is not a separately measured network outage. No USER connection-interruption messages were recorded. The highest sampled temperature was 72.375 °C, below the observer’s conservative 85 °C cutoff, which is a test policy rather than a hardware certification.

Scope and preserved evidence

The saved result still says full_24h_observation_completed: false. Its live_smoke_passed: false field requires a zero exit code and no stop request, so it remains false for this deliberate interruption; it has not been rewritten. The log records worker cleanup, and the original miner and observer were absent with their locks released when checked afterward.

This was one Linux desktop with 192 threads and 192 huge-page workers. GPU mining and normal desktop activity were preserved. USER and FEE used the same maintainer-controlled wallet with distinct workers, so separate-wallet settlement was not independently verified. Repeated fee cycles, extended stability, other platforms, comprehensive security and matched speed or earnings gains are not established. Unreported metrics are not inferred to be zero.

The 110.342 kH/s figure is a displayed gross session average, not net user payout or a new comparative benchmark. The historical 110.615 kH/s development reference remains unchanged.

Known beta limitations

The developer-fee schedule resets after restart. The duplicate-input cache stops the beta at 32,768 entries. Non-root huge-page permissions vary by system. No Windows, macOS, ARM, or GPU package is provided. Preserve logs and do not bypass failed integrity or hash checks.

Report a problem

Use the GitHub bug or benchmark forms and the feedback template. Redact secrets, full payout addresses, and private network details. No private security-reporting channel is verified; obtain one from the owner before sharing sensitive vulnerability details.
