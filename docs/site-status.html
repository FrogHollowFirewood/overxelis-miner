Current beta.4 hotfix: selected-kernel crash protection

Beta.4 crash fix · upgrade to source preview 2. The earlier beta.4 source preview 1 can stop with an integer divide-by-zero fault, shown by the shell as “floating point exception.” Preview 2 checks the selected production kernel before that division, consumes the failed nonce, and excludes it from completed work and share submission. The first failing input is retained in the native runtime for diagnostics; the public launcher does not automatically save it to disk. The cause of the original zero intermediate value remains unverified because that input was not saved. Read the fix, qualification and limits.

Known beta limitations

The developer-fee schedule resets after restart. Beta.4 retains bounded lifetime nonce tracking for the native engine; the historical beta.2 duplicate-input cache limit is not its normal native-engine limit. Non-root huge-page permissions vary by system. The 192-thread profile is optional and specific to suitable hardware; it is not a universal fastest setting. No Windows, macOS, ARM or GPU package is provided. Preserve logs and stop on failed integrity or hash checks.
