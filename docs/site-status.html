Beta.3: completed public-package checks

1 November 2026 (UTC). The exact 1.0.0-beta.3 / public-source-preview.1 source archive was built and qualified as a normal user on the maintainer’s AMD Ryzen Threadripper PRO 7995WX. The selected profile used 192 threads, huge pages and GCC 14.3, with a normal non-PGO build. This is a qualified beta preview with finite test evidence, not a general stability or performance guarantee.

Correctness and workers

124 production tests and 15 tuning-tool tests passed. Native qualification replayed 1,031 saved Rust-reference inputs through four C hash implementations and performed 1,031 full scratchpad comparisons. The CLI self-test passed. Actual layout qualification verified one reference-checked terminal nonce for each of all 192 huge-page workers, with no drops. Rust was not newly built or executed.

Completed live pool run

A normal 300-second USER pool run returned code 0 with 38 accepted shares and zero reported rejected, unresolved, local stale, duplicate or invalid shares and queue drops. All workers closed and the CPU lock was released. The final local session average was 110.870 kH/s, including startup and job waits, rounded to 0.001 kH/s. This is an application-local rate, not a pool-side rate or earnings result.

Measured native improvement

Four matched 60-second samples per build, each after a 15-second warmup, averaged 111.168 kH/s for beta.3 versus 110.234 kH/s for beta.2 using the same compiler, CPU order and memory mode. The aggregate improvement was 0.85%. All four beta.3 samples exceeded the 110.615 kH/s target. The public package’s native library is byte-identical to the measured candidate. Known beta limitations

The developer-fee schedule resets after restart. Beta.3 uses bounded lifetime nonce tracking for the native engine; the historical beta.2 duplicate-input cache limit is not the normal native-engine limit in beta.3. Non-root huge-page permissions vary by system. The 192-thread profile is optional and specific to suitable hardware; it is not a universal fastest setting. No Windows, macOS, ARM or GPU package is provided. Preserve logs and stop on failed integrity or hash checks.

Report a problem

Use the GitHub bug or benchmark forms and the feedback template. Redact secrets, full payout addresses, and private network details. No private security-reporting channel is verified; obtain one from the owner before sharing sensitive vulnerability details.
